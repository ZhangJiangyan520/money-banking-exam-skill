## 📚 核心知识点清单
### 一、名词解释
1. 基础货币：又称高能货币，由流通中的现金与商业银行存款准备金构成，是中央银行直接控制的货币。
2. 货币乘数：货币供给量与基础货币的比值，代表基础货币扩张或者收缩货币供给的倍数。
3. 派生存款：商业银行以原始存款为基础，通过发放贷款、办理贴现等资产业务，衍生创造出来的存款。
4. 通货膨胀：在一定时期内，一般物价水平持续、普遍上涨的货币现象。
5. 公开市场业务：中央银行在金融市场上买卖有价证券，以此调节市场货币供应量的货币政策工具。

### 二、计算公式
1. 简单货币乘数：m = 1 / 法定存款准备金率
2. 完整货币乘数：m = (1 + 现金漏损率) / (法定存款准备金率 + 超额准备金率 + 现金漏损率)
3. 费雪方程式：MV = PT

### 三、简答要点
✅ 三大一般性货币政策工具：法定存款准备金政策、再贴现政策、公开市场业务。
✅ 凯恩斯利率理论：利率由货币的供给与货币的需求共同决定。
